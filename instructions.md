# Workspace Operating Guidelines for External Agents

## Project Scope
- Client: Okaz Manpower Recruitment (شركة عكاظ لجلب الأيدي العاملة)
- Focus: Landing Page & Portfolio for Qatar Domestic Workers Recruitment Campaigns
- Primary Language: Arabic (RTL layout)

## Core Technical Standards
1. Strict Vanilla Web Architecture: Pure HTML5, modern CSS3, and ES6+ JavaScript.
2. Absolute Zero Emoji Policy: No emojis permitted in code, UI, text, or documentation.
3. Protected Directory: Do NOT modify or delete the canonical `AI/` context directory.
4. Serving Command: `python -m http.server 8080`
